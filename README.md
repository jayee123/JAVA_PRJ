## 系統介紹

校園活動管理系統是一套以 Java Swing 製作的桌面應用程式，讓學生與主辦者可以透過圖形介面管理校園活動。

### 主要功能

| 角色 | 功能 |
|------|------|
| **學生** | 瀏覽即將舉行的活動、報名活動、取消報名、查看個人報名紀錄 |
| **主辦者** | 建立 / 編輯 / 刪除活動、查看報名名單、匯出名單為 CSV |

### 帳號規則

| 帳號開頭 | 角色 |
|----------|------|
| `S`（大小寫皆可） | 學生帳號，例如 `S001`、`s101` |
| `O`（大小寫皆可） | 主辦者帳號，例如 `O001`、`o01` |

---

## 技術架構

```
JAVA_prj_v2/
├── MainGUI.java      ← 圖形介面主程式（登入、學生、主辦者三個畫面）
├── Main.java         ← 程式進入點
├── User.java         ← 使用者抽象類別
├── Student.java      ← 學生類別（繼承 User）
├── Organizer.java    ← 主辦者類別（繼承 User）
├── Event.java        ← 活動類別（含報名名單、CSV 序列化）
├── Registerable.java ← 可報名介面
├── FileManager.java  ← 讀寫 CSV 資料檔
├── events.csv        ← 活動資料（自動產生）
└── users.csv         ← 使用者資料（自動產生）
```

**資料流向**
```
啟動 → FileManager 讀取 events.csv / users.csv
操作 → 寫入記憶體 List
關閉 or 每次異動 → FileManager 儲存回 CSV
```

## 執行方式

### 編譯

```bash
javac -encoding UTF-8 *.java
```

### 執行

```bash
java Main
```

> 需要 Java 8 以上版本。首次執行時 `events.csv` 與 `users.csv` 不存在沒有關係，系統會自動建立。

## 資料檔案說明

### users.csv

每行一筆使用者，格式：

```
帳號ID,姓名,角色
```

範例：
```
S001,王小明,S
O001,李主辦,O
```

### events.csv

每行一筆活動，格式：

```
活動ID,標題,地點,名額,主辦者ID,日期,時間,報名學生ID
```

- 報名學生 ID 以 `;` 分隔；無人報名時填 `NONE`
- 日期格式：`YYYY-MM-DD`
- 時間格式：`HH:MM`

範例：
```
E001,期末成果展,大禮堂,100,O001,2026-06-15,09:00,S001;S002
E002,程式競賽,電腦教室,30,O001,2026-07-01,13:00,NONE
```

## 登入頁面操作手冊

### 畫面說明

```
┌─────────────────────────────┐
│       校園活動管理系統        │
│  Campus Event Management    │
│                             │
│  登入 ID                    │
│  [ 輸入帳號 ID            ] │
│                             │
│  [        登 入           ] │
│  [ 首次登入（建立新帳號）  ] │
└─────────────────────────────┘
```

---

### 一般登入（已有帳號）

1. 在「登入 ID」欄位輸入你的帳號（例：`S001`）
2. 按下 **「登 入」** 按鈕，或按鍵盤 **Enter**
3. 帳號驗證成功 → 進入對應介面
4. 帳號不存在 → 顯示錯誤訊息，不會登入

> 登入 ID 不區分大小寫，`s001` 和 `S001` 視為同一帳號。

---

### 首次登入（建立新帳號）

1. 按下 **「首次登入（建立新帳號）」** 按鈕
2. 跳出建立帳號視窗：

```
┌──────────────────────────────┐
│  首次登入 － 建立新帳號       │
│                              │
│  S 開頭=學生 · O 開頭=主辦者 │
│                              │
│  登入 ID                     │
│  [ S001                    ] │
│                              │
│  姓名                        │
│  [ 王小明                  ] │
│                              │
│  [    建立帳號並登入        ] │
└──────────────────────────────┘
```

3. 填入 **登入 ID**（S 或 O 開頭）與 **姓名**
4. 按 **「建立帳號並登入」** → 帳號建立完成並直接進入系統
5. 姓名欄可留空，系統會自動填入預設名稱（例：`學生_S001`）

**注意事項：**
- 帳號 ID 必須以 `S` 或 `O` 開頭，否則無法建立
- 若輸入的 ID 已被其他人使用，會顯示錯誤，請改用其他 ID

## 學生介面操作手冊

登入後進入學生介面，上方顯示歡迎訊息與登出按鈕，下方有兩個分頁。

```
┌─────────────────────────────────────────────────────┐
│ 校園活動管理系統 | 學生介面   歡迎，王小明（S001）  登出 │
├──────────────┬──────────────────────────────────────┤
│  所有活動    │  我的報名紀錄                         │
└──────────────┴──────────────────────────────────────┘
```

---

### 分頁一：所有活動

顯示**目前尚未結束**的所有活動清單，依日期時間排序。

**欄位說明：**

| 欄位 | 說明 |
|------|------|
| 活動ID | 活動的唯一代號 |
| 標題 | 活動名稱 |
| 日期 / 時間 | 活動舉行的日期與時間 |
| 地點 | 活動地點 |
| 報名/名額 | 目前報名人數 / 總名額（例：`3/50`） |
| 狀態 | `開放報名` 或 `額滿` |

**操作步驟：**

#### 查看活動詳情
1. 在清單中**點選一筆活動**（點選後該行會反藍）
2. 按下 **「查看詳情」** 按鈕
3. 彈出視窗顯示：活動 ID、標題、地點、日期時間、主辦者、名額、狀態、完整報名名單

#### 報名活動
1. 在清單中**點選想報名的活動**
2. 按下 **「報名活動」** 按鈕
3. 報名成功 → 顯示成功提示，報名人數 +1
4. 報名失敗的可能原因：
   - 活動已額滿
   - 您已經報名過此活動

#### 取消報名（從所有活動頁）
1. 在清單中**點選已報名的活動**
2. 按下 **「取消報名」** 按鈕
3. 取消成功 → 報名人數 -1

---

### 分頁二：我的報名紀錄

顯示**目前已報名**的所有活動（包含過去與未來的活動）。

**操作步驟：**

#### 查看詳情
1. **點選一筆活動**
2. 按下 **「查看詳情」**

#### 取消報名
1. **點選要取消的活動**
2. 按下 **「取消報名」**
3. 取消成功後，該筆紀錄從列表移除

#### 重新整理
- 按下 **「重新整理」** 可強制重新載入最新資料
- 不需要先選取活動，直接按即可

---

### 登出（學生）

- 按右上角 **「登出」** 按鈕 → 回到登入頁面
- 登出時系統會自動儲存所有資料

## 主辦者介面操作手冊

登入後進入主辦者介面，顯示**所有活動**的完整清單（含已結束的活動）。

```
┌──────────────────────────────────────────────────────────────────┐
│ 校園活動管理系統 | 主辦者介面   歡迎，李主辦（O001）           登出 │
├──────────────────────────────────────────────────────────────────┤
│  活動ID │ 標題 │ 日期 │ 時間 │ 地點 │ 主辦者 │ 報名/名額 │ 狀態 │
│  ...                                                             │
├──────────────────────────────────────────────────────────────────┤
│ [建立活動] [編輯活動] [刪除活動] [查看詳情] [匯出名單 CSV]        │
└──────────────────────────────────────────────────────────────────┘
```

**狀態欄說明：**

| 狀態 | 意義 |
|------|------|
| 開放中 | 活動尚未結束且名額未滿 |
| 額滿 | 活動尚未結束但名額已滿 |
| 已結束 | 活動日期時間已過 |

---

### 建立活動

> 不需要先選取活動，直接按按鈕即可。

1. 按下 **「建立活動」**
2. 填寫表單：

| 欄位 | 說明 | 範例 |
|------|------|------|
| 活動 ID | 唯一代號，不可重複 | `E001` |
| 標題 | 活動名稱 | `期末成果展` |
| 地點 | 舉辦地點 | `大禮堂` |
| 名額 | 最多可報名人數（正整數） | `100` |
| 日期 | 格式必須為 `YYYY-MM-DD` | `2026-06-15` |
| 時間 | 格式必須為 `HH:MM` | `09:00` |

3. 按 **「建立」** 確認，或按 **「取消」** 放棄

**注意事項：**
- 活動 ID、標題、地點為必填
- 活動 ID 若與現有活動重複，會顯示錯誤
- 日期與時間格式錯誤也會顯示錯誤

---

### 編輯活動

> 只能編輯**自己主辦**的活動。

1. 在清單中**點選要編輯的活動**
2. 按下 **「編輯活動」**
3. 修改需要變更的欄位（不需要改的欄位保持原值即可）
4. 按 **「儲存」** 確認

**注意事項：**
- 名額不可設定為**小於目前已報名人數**（否則資料會不一致）
- 活動 ID 不可在編輯中變更

---

### 刪除活動

> 只能刪除**自己主辦**的活動，刪除後**無法復原**。

1. 在清單中**點選要刪除的活動**
2. 按下 **「刪除活動」**
3. 出現確認視窗：「確定刪除『XXX』？此操作無法復原。」
4. 按 **「是」** → 活動刪除並從清單移除
5. 按 **「否」** → 取消，不做任何變更

---

### 查看詳情

1. 在清單中**點選任一活動**
2. 按下 **「查看詳情」**
3. 顯示完整資訊，包含**所有報名學生的 ID 列表**

---

### 匯出名單 CSV

1. 在清單中**點選要匯出名單的活動**
2. 按下 **「匯出名單 CSV」**
3. 系統在**程式執行目錄**下產生檔案，檔名格式：

```
participants_活動ID.csv
```

例如活動 ID 為 `E001`，則產生 `participants_E001.csv`

**CSV 內容範例：**
```
StudentID
S001
S002
S003
```

---

### 登出（主辦者）

- 按右上角 **「登出」** 按鈕 → 回到登入頁面
- 登出時系統會自動儲存所有資料

## 錯誤訊息說明

| 錯誤訊息 | 原因 | 解決方式 |
|----------|------|----------|
| 請輸入登入 ID！ | 登入欄位為空 | 填入帳號後再按登入 |
| 帳號不存在！ | 輸入的 ID 在系統中找不到 | 確認 ID 是否正確，或改用「首次登入」建立帳號 |
| 無效的 ID！ | 帳號開頭不是 S 或 O | 使用 S 或 O 開頭的帳號 |
| 此帳號已存在！ | 首次登入時輸入了已存在的 ID | 改用其他 ID，或關閉視窗直接登入 |
| 請先選擇一個活動！ | 按按鈕前沒有選取活動 | 先點選清單中的一筆活動再操作 |
| 報名失敗！（活動已額滿，或您已報名此活動） | 名額已滿，或重複報名 | 選擇其他活動，或確認是否已報名 |
| 您只能編輯自己主辦的活動！ | 嘗試編輯他人建立的活動 | 只能操作自己建立的活動 |
| 名額不能小於已報名人數 | 編輯時將名額調低於目前人數 | 將名額設定為大於或等於目前已報名人數 |
| 日期格式錯誤（YYYY-MM-DD）！ | 日期格式不正確 | 請依格式輸入，例如 `2026-06-15` |
| 時間格式錯誤（HH:MM）！ | 時間格式不正確 | 請依格式輸入，例如 `09:00` |
| 活動 ID「XXX」已存在！ | 建立活動時輸入了重複的 ID | 更換一個不重複的活動 ID |
